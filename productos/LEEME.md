# Aquí van tus fotografías

Sube aquí las imágenes que quieras usar en el catálogo. Por ejemplo:

- chocotejas-rellenas.webp
- trufas-cacao.jpg
- alfajores-maicena.webp

Después abre productos.json en la raíz del repositorio y cambia el campo imagen del producto para que use una ruta como productos/chocotejas-rellenas.webp.

Consejo: usa JPG o WebP, fotos verticales o cuadradas, y procura que cada archivo pese menos de 250 KB para que cargue rápido en el celular.
